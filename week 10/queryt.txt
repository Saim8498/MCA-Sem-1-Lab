SQL Solution: Banking Database
a) Create the tables with primary keys and foreign keys
The following SQL statements create all six tables with appropriate primary key and foreign key constraints.

sql
CREATE TABLE BRANCH (
    branch_name VARCHAR(50) PRIMARY KEY,
    branch_city VARCHAR(50),
    assets REAL
);

CREATE TABLE ACCOUNT (
    accno INT PRIMARY KEY,
    branch_name VARCHAR(50),
    balance REAL,
    FOREIGN KEY (branch_name)
        REFERENCES BRANCH(branch_name)
);

CREATE TABLE CUSTOMER (
    customer_name VARCHAR(50) PRIMARY KEY,
    customer_street VARCHAR(100),
    customer_city VARCHAR(50)
);

CREATE TABLE DEPOSITOR (
    customer_name VARCHAR(50),
    accno INT,
    PRIMARY KEY (customer_name, accno),
    FOREIGN KEY (customer_name)
        REFERENCES CUSTOMER(customer_name),
    FOREIGN KEY (accno)
        REFERENCES ACCOUNT(accno)
);

CREATE TABLE LOAN (
    loan_number INT PRIMARY KEY,
    branch_name VARCHAR(50),
    amount REAL,
    FOREIGN KEY (branch_name)
        REFERENCES BRANCH(branch_name)
);

CREATE TABLE BORROWER (
    customer_name VARCHAR(50),
    loan_number INT,
    PRIMARY KEY (customer_name, loan_number),
    FOREIGN KEY (customer_name)
        REFERENCES CUSTOMER(customer_name),
    FOREIGN KEY (loan_number)
        REFERENCES LOAN(loan_number)
);

c) Find all customers who have at least two accounts at the main branch
SQL query:

sql
SELECT D.customer_name
FROM DEPOSITOR D
JOIN ACCOUNT A ON D.accno = A.accno
WHERE A.branch_name = 'Main'
GROUP BY D.customer_name
HAVING COUNT(DISTINCT D.accno) >= 2;
Explanation:

Join DEPOSITOR and ACCOUNT to identify the branch for each customer's account.

Filter accounts belonging to the Main branch.

Group records by customer.

Use HAVING to select customers who have at least two distinct accounts.

Expected output:

customer_name

Amit

Amit has accounts 101 and 102 at the Main branch.

d) Find all customers who have an account at all branches in a specific city
For example, find customers who have an account at every branch in Delhi.

SQL query (using double NOT EXISTS):

sql
SELECT C.customer_name
FROM CUSTOMER C
WHERE NOT EXISTS (
    SELECT 1
    FROM BRANCH B
    WHERE B.branch_city = 'Delhi'
      AND NOT EXISTS (
          SELECT 1
          FROM DEPOSITOR D
          JOIN ACCOUNT A ON D.accno = A.accno
          WHERE D.customer_name = C.customer_name
            AND A.branch_name = B.branch_name
      )
);
Explanation:

The outer NOT EXISTS checks that no required branch is missing from the customer's accounts.

The inner NOT EXISTS finds a branch in Delhi where the customer does not have an account.

Therefore, the query returns customers who have an account at every branch in Delhi.

Expected output for the sample data: No rows, because Delhi has two branches (Main and City Center), and no customer has accounts at both branches.

e) Delete all account tuples at every branch located in a specific city
For example, delete all accounts belonging to branches located in Delhi.

Since DEPOSITOR references ACCOUNT, delete the corresponding depositor records first to avoid foreign key violations.

sql
DELETE FROM DEPOSITOR
WHERE accno IN (
    SELECT A.accno
    FROM ACCOUNT A
    JOIN BRANCH B
      ON A.branch_name = B.branch_name
    WHERE B.branch_city = 'Delhi'
);

DELETE FROM ACCOUNT
WHERE branch_name IN (
    SELECT branch_name
    FROM BRANCH
    WHERE branch_city = 'Delhi'
);
Explanation:

The first statement deletes the depositor records associated with accounts at Delhi branches.

The second statement deletes all accounts belonging to branches located in Delhi.

The BRANCH records themselves are not deleted.
